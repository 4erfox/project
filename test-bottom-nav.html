Статус компонента Активен

Универсальный нижний навбар загружен и работает на всех устройствах.

  • Отображается на desktop (> 768px)
  • Отображается на mobile (≤ 768px)
  • Фиксированная позиция внизу экрана
  • 5 элементов навигации (4 обычных + 1 логотип)
  • Центральная иконка поднята вверх
  • Badge на кнопке Daily

Ключевые особенности

  • Темный полупрозрачный фон с blur эффектом
  • Плавные анимации при hover и клике
  • Красный цвет (#E53935) для активных элементов
  • Центральная иконка 56x56px с градиентом
  • Обычные иконки 24x24px
  • Красная пульсирующая точка для Daily
  • Адаптивный дизайн для разных экранов
  • Safe area для iOS устройств
  • Accessibility support (aria-labels, keyboard nav)

Тестирование Интерактивно

Попробуйте следующие действия:

  • Наведите курсор на иконки (должны увеличиться)
  • Нажмите на любую иконку (переход на страницу)
  • Обратите внимание на красную точку у Daily
  • Центральная иконка поднята выше остальных
  • Активная страница отмечена красным цветом
  • Измените размер окна (responsive)

Адаптивность

Desktop (> 768px):

  • Навбар центрирован, max-width: 600px
  • Закругленные верхние углы
  • Увеличенный padding

Mobile (≤ 768px):

  • Полная ширина экрана
  • Без закругления углов
  • Меньший padding
  • Логотип 52x52px

Extra Small (≤ 380px):

  • Уменьшенные иконки: 20x20px
  • Логотип 48x48px
  • Минимальный padding

Технические детали

Файлы:

  • /js/BottomNavBar.js - основной компонент
  • /src/main.js - импорт и инициализация
  • Встроенные стили в компоненте

Зависимости:

  • Нет внешних зависимостей
  • Чистый JavaScript (ES6+)
  • CSS3 с современными фичами
  • SVG иконки (Lucide Icons)
