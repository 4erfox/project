# Мобильный навбар - Документация

## Обзор

Мобильный навбар автоматически отображается на экранах шириной менее 768px и фиксируется внизу экрана для удобного доступа к основным разделам учебника.

## Структура файлов

### 1. `/js/navItems.js`

Конфигурационный файл, содержащий определение элементов навигации.

#### Структура элемента навигации:

```javascript
{
  id: 'home',                  // Уникальный идентификатор
  label: 'Главная',            // Текст метки
  icon: '<svg>...</svg>',      // SVG иконка (Lucide Icons)
  path: '/index.html',         // Путь для навигации
  description: '...',          // Описание для accessibility
  showBadge: true              // Отображать уведомление (опционально)
}
```

#### Доступные функции:

1. **getNavItemById(id)**
   - Получить элемент навигации по ID
   - Параметры: `id` (string)
   - Возвращает: объект элемента или `undefined`

2. **getNavItemByPath(path)**
   - Получить элемент навигации по пути
   - Параметры: `path` (string)
   - Возвращает: объект элемента или `undefined`

3. **getAllNavItems()**
   - Получить все элементы навигации
   - Возвращает: массив всех элементов

4. **hasNotificationBadge(id)**
   - Проверить наличие badge у элемента
   - Параметры: `id` (string)
   - Возвращает: `true` или `false`

#### Примеры использования:

```javascript
import { getNavItemById, getNavItemByPath, hasNotificationBadge } from './js/navItems.js';

// Получить элемент по ID
const homeItem = getNavItemById('home');
console.log(homeItem.label); // 'Главная'

// Получить элемент по пути
const currentItem = getNavItemByPath('/osnovyi.html');
console.log(currentItem.id); // 'course'

// Проверить наличие badge
const hasBadge = hasNotificationBadge('daily');
console.log(hasBadge); // true
```

### 2. `/js/MobileNavBar.js`

Основной класс для управления мобильным навбаром.

#### Особенности:

- Автоматическая инициализация при загрузке страницы
- Определение активной страницы на основе текущего пути
- Обработка навигации между страницами
- Визуальная индикация активного элемента
- Отображение badge для элементов с уведомлениями

#### Стилизация:

- Фиксированная позиция внизу экрана
- Высота: 64px + safe-area-inset-bottom
- Темный фон с эффектом blur
- Адаптивные иконки с плавными переходами
- Цвет активного элемента: #E53935 (красный)
- Цвет неактивных элементов: #9CA3AF (серый)

## Элементы навигации

### 1. Главная
- **ID:** home
- **Иконка:** Home (дом)
- **Путь:** /index.html
- **Описание:** Главная страница учебника

### 2. Курс
- **ID:** course
- **Иконка:** BookOpen (открытая книга)
- **Путь:** /osnovyi.html
- **Описание:** Каталог разделов обучения

### 3. Daily
- **ID:** daily
- **Иконка:** Dices (кубики)
- **Путь:** /praktika.html
- **Описание:** Ежедневная практическая ситуация
- **Badge:** Да (красная точка)

### 4. Прогресс
- **ID:** progress
- **Иконка:** BarChart3 (столбчатая диаграмма)
- **Путь:** /kontakty.html
- **Описание:** Личная статистика и достижения

## Использование в HTML

Навбар автоматически загружается при подключении `/src/main.js`:

```html
<script type="module" src="/src/main.js"></script>
```

## Тестирование

Откройте файл `test-nav.html` для проверки работы навбара и функций:

1. Откройте файл в браузере
2. Уменьшите ширину окна до менее 768px
3. Навбар должен появиться внизу экрана
4. Проверьте результаты тестов функций на странице

## Адаптивность

- **Десктоп (> 768px):** навбар скрыт
- **Планшет/Мобильный (≤ 768px):** навбар отображается внизу

## Accessibility

- Все кнопки имеют `aria-label` для скринридеров
- Активная страница отмечена `aria-current="page"`
- Badge имеет `aria-label="Новое уведомление"`
- Навбар имеет `role="navigation"`

## Кастомизация

### Изменить иконки

Отредактируйте SVG в массиве `NAV_ITEMS` в файле `/js/navItems.js`.

### Изменить цвета

Измените следующие значения в `/js/MobileNavBar.js`:

```javascript
// Цвет активного элемента
color: ${isActive ? '#E53935' : '#9CA3AF'}

// Цвет badge
background-color: #EF4444;

// Фон навбара
background: rgba(26, 26, 26, 0.95);
```

### Добавить новый элемент

Добавьте новый объект в массив `NAV_ITEMS` в файле `/js/navItems.js`:

```javascript
{
  id: 'new-item',
  label: 'Новый',
  icon: '<svg>...</svg>',
  path: '/new-page.html',
  description: 'Описание нового элемента'
}
```

## Решение проблем

### Навбар не отображается

1. Проверьте ширину экрана (должна быть ≤ 768px)
2. Откройте консоль браузера для проверки ошибок
3. Убедитесь, что `/src/main.js` подключен

### Навигация не работает

1. Проверьте правильность путей в `NAV_ITEMS`
2. Убедитесь, что HTML файлы существуют
3. Проверьте консоль браузера на ошибки JavaScript

### Badge не отображается

Убедитесь, что элемент имеет `showBadge: true` в `/js/navItems.js`.
