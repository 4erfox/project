# Универсальный нижний навбар - Документация

## Обзор

Универсальный нижний навбар отображается на **всех устройствах** (desktop и mobile) и фиксируется внизу экрана для удобного доступа к основным разделам учебника.

## Ключевые особенности

- Отображается на ВСЕХ размерах экрана (не только mobile)
- 5 элементов навигации: 4 обычных + 1 центральный логотип
- Темный полупрозрачный фон с blur эффектом
- Центральная иконка поднята выше остальных
- Плавные анимации и hover эффекты
- Красная точка-badge для Daily раздела
- Responsive дизайн с адаптацией под разные экраны

## Структура файлов

### `/js/BottomNavBar.js`

Основной файл компонента, содержащий:

1. **NAV_CONFIG** - конфигурация элементов навигации
2. **BottomNavBar** - класс управления навбаром
3. **initBottomNavBar()** - функция инициализации

## Дизайн и стилизация

### Общий фон
```css
background: rgba(26, 26, 26, 0.95)
backdrop-filter: blur(16px)
border-top: 1px solid rgba(255, 255, 255, 0.08)
box-shadow: 0 -4px 24px rgba(0, 0, 0, 0.3)
```

### Обычные кнопки
- **Иконка**: 24x24px
- **Цвет неактивная**: #9CA3AF (серый)
- **Цвет активная**: #E53935 (красный)
- **Шрифт**: 11px
- **Hover**: scale(1.1)
- **Active**: translateY(-2px)

### Центральный логотип
- **Размер**: 56x56px
- **Фон**: linear-gradient(135deg, #E53935 0%, #C62828 100%)
- **Рамка**: 3px solid #1a1a1a
- **Форма**: круг (border-radius: 50%)
- **Позиция**: translateY(-12px)
- **Тень**: 0 4px 16px rgba(229, 57, 53, 0.4)
- **Hover**: scale(1.05) + больше тень
- **Иконка**: 32x32px, белая

### Badge (красная точка)
- **Размер**: 8px
- **Цвет**: #EF4444
- **Позиция**: top-right
- **Анимация**: pulse (пульсация)

## Адаптивность

### Desktop (> 768px)
- Навбар центрирован, max-width: 600px
- Закругленные верхние углы (border-radius: 24px 24px 0 0)
- Padding: 8px 24px

### Mobile (≤ 768px)
- Полная ширина экрана
- Без закругления углов
- Padding: 8px 16px
- Центральный логотип: 52x52px

### Extra Small (≤ 380px)
- Уменьшенные иконки: 20x20px
- Центральный логотип: 48x48px
- Меньший padding между элементами

## Интерактивность

### Hover эффекты
- Обычные кнопки: увеличение (scale 1.1)
- Центральный логотип: легкое увеличение + усиление тени
- Плавные transitions: 200-300ms

### Click эффекты
- Обычные кнопки: сдвиг вверх (-2px)
- Центральный логотип: уменьшение (scale 0.95)

### Активное состояние
- Красный цвет (#E53935)
- Жирность шрифта: 600
- Увеличенная толщина stroke: 2.5

## Accessibility

- **role="navigation"** - роль навигации
- **aria-label** на каждой кнопке
- **aria-current="page"** для активной страницы
- **aria-label** для badge ("Новое уведомление")
- Поддержка keyboard navigation
- Safe area для iOS (env(safe-area-inset-bottom))

## Использование

Навбар автоматически инициализируется при загрузке страницы через импорт в `/src/main.js`:

```javascript
import '../js/BottomNavBar.js';
```

## Отступы для контента

Чтобы нижний навбар не перекрывал контент, добавлены отступы:

- **body**: padding-bottom: 88px
- **.page-content**: padding-bottom: 88px

## Кастомизация

### Изменить иконки
Отредактируйте SVG в массиве `NAV_CONFIG.items` в файле `/js/BottomNavBar.js`

### Изменить цвета
Основные цвета в стилях:

```javascript
// Активный цвет
color: #E53935

// Неактивный цвет
color: #9CA3AF

// Фон навбара
background: rgba(26, 26, 26, 0.95)

// Градиент логотипа
background: linear-gradient(135deg, #E53935 0%, #C62828 100%)

// Цвет badge
background-color: #EF4444
```

### Добавить новый элемент
Добавьте новый объект в `NAV_CONFIG.items`:

```javascript
{
  id: 'new-item',
  label: 'Новый',
  icon: '<svg>...</svg>',
  path: '/new-page.html',
  showBadge: false // опционально
}
```

## Решение проблем

### Навбар перекрывает контент
Убедитесь, что добавлены отступы:
- `body { padding-bottom: 88px; }`
- `.page-content { padding-bottom: 88px; }`

### Навигация не работает
Проверьте правильность путей в `NAV_CONFIG.items` и существование HTML файлов.

### Badge не отображается
Убедитесь, что элемент имеет `showBadge: true` в конфигурации.

### Центральная иконка не поднята
Проверьте наличие класса `.nav-logo-item` и стиля `transform: translateY(-12px)`.
