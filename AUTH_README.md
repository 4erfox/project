# Система авторизации ЭтикетPro

## Что было реализовано

Добавлена полнофункциональная система авторизации через Supabase:

### ✅ Функции

1. **Регистрация** - создание нового аккаунта с email и паролем
2. **Вход** - вход в существующий аккаунт
3. **Выход** - выход из аккаунта
4. **Сохранение сессии** - автоматическое восстановление сессии при загрузке страницы

### 📁 Новые файлы

- **`src/auth.js`** - основная логика авторизации (интеграция с Supabase)
- **`src/authModal.js`** - модальные окна логина и регистрации
- **`src/authStyles.css`** - стили для форм авторизации

### 🎨 UI элементы

- **Кнопка "Вход"** в навбаре (справа)
- **Модальное окно** с табами для входа и регистрации
- **Меню пользователя** (видно после входа вместо кнопки)
- **Кнопка "Выход"** в меню пользователя

## Как использовать

### Локальное тестирование

1. Откройте сайт в браузере
2. Нажмите кнопку "Вход" в правом углу навбара
3. Выберите "Зарегистрироваться" и создайте аккаунт
4. Введите email и пароль (минимум 6 символов)
5. После регистрации вы сможете войти

### Тестовые учетные данные (если нужны)

Создайте свой тестовый аккаунт через регистрацию.

## Как работает

### Процесс авторизации

```
1. При загрузке страницы → initAuth() проверяет текущую сессию
2. Если пользователь уже авторизован → показываем его меню
3. Если нет → показываем кнопку "Вход"
4. При клике на кнопку → открываем модальное окно
5. После регистрации/входа → обновляем UI
```

### Хранение данных

- Сессия хранится в браузере автоматически
- При перезагрузке страницы сессия восстанавливается
- При выходе сессия удаляется

## Возможные проблемы

### Авторизация не работает

1. Проверьте консоль браузера (F12) на ошибки
2. Убедитесь, что `.env` файл содержит правильные ключи Supabase
3. Перезагрузите страницу
4. Очистите кэш браузера (Ctrl+Shift+Del)

### CORS ошибки

Если видите CORS ошибки - это нормально для локальной разработки. В production они не будут.

### Ошибка "Не удалось подключиться"

- Проверьте интернет соединение
- Убедитесь, что Supabase доступен (https://supabase.com status)
